# Каталог книг — лабораторная работа № 3

Каталог хранит библиотечные книги, ищет их по названию и категории, сохраняет
и загружает данные в JSON.

## Быстрый старт

Откройте PowerShell в папке с `pyproject.toml`
и установите проект.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install ".[test]"
```

## Пример работы

После установки запустите пакет из папки с `pyproject.toml`.

```powershell
.\.venv\Scripts\python.exe -m src.bookcatalog
```

В консоли появится результат поиска книги по части названия.

```text
Поиск по названию «ОТЦЫ»
«Отцы и дети», Иван Тургенев, 1862 г.
```

Установленный пакет также запускается командой `python -m bookcatalog`.

### Работа с каталогом из Python

Откройте консоль Python.

```powershell
.\.venv\Scripts\python.exe
```

```python
from bookcatalog import Book, Catalog

catalog = Catalog()
book = Book("b-1", "Отцы и дети", "Роман", 1862, "Иван Тургенев", 240)

with catalog.transaction():
    catalog.add(book)

for found in catalog.find_by_name("ОТЦЫ"):
    print(f"Найдена книга — {found}")

print(f"Автор — {catalog.read_only_view()['b-1'].author}")
catalog.save_json("books.json")
```

В консоли появятся название книги и автор, а в текущей папке — файл
`books.json`.

## Как устроен каталог

`Book` хранит ID, название, категорию, год издания, автора и число страниц.
Строковые поля должны содержать хотя бы один непробельный символ. Год и число
страниц — положительные целые числа. Поля проверяются при создании книги.
Книга после создания неизменяема.

Каталог хранит книги в словаре по ID. Итерация идёт в порядке добавления.
Если удалить книгу и добавить её снова, она окажется в конце. Поиск по
имени ищет подстроку без учёта регистра, поиск по категории ищет точное
совпадение. Оба возвращают новый список в порядке добавления.

`save_json` записывает книги в UTF-8. В корне JSON находятся `format_version`
(сейчас 1) и список `items`. `load_json` сначала собирает временный каталог
и после успешной проверки заменяет текущие книги.
Ошибки каталога наследуются от `CatalogError`.

## Дополнительные задания

### Индекс по категории (+3)

Для каждой категории хранится словарь её книг. Добавление, удаление и загрузка
обновляют индекс вместе с основным словарём.

### Снимок только для чтения (+2)

`read_only_view()` возвращает копию словаря, защищённую от изменений.
Последующие изменения каталога в ней не появляются.

### Транзакция с откатом (Challenge, +5)

`with catalog.transaction():` сохраняет состояние каталога при входе. Если
из блока выходит исключение, восстанавливаются книги, их порядок и индекс.
При обычном выходе изменения сохраняются. Откат действует на каталог в памяти.
